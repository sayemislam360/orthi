# অর্থির জন্মদিনের ওয়েবসাইট ♡

শুধু অর্থির জন্য বানানো একটা ছোট্ট জন্মদিনের সারপ্রাইজ ওয়েবসাইট।

## ছবি বদলানোর নিয়ম

`assets/images/` ফোল্ডারে নিজের ছবিগুলো এই নামে রাখো:

`photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg`, `photo5.jpg`, `photo6.jpg`

- ছবি না থাকলে সুন্দর একটা খালি জায়গা দেখাবে, ওয়েবসাইট নষ্ট হবে না।
- ছবি চৌকো (square) হলে সবচেয়ে ভালো দেখায়।
- ছবির নিচের লেখা বদলাতে `index.html` খুলে `<figcaption>` খোঁজো।

## চিঠি বদলানো

`index.html` ফাইলে `<div class="paper-in">` খুঁজে নিজের কথা লিখে দাও।

## GitHub Pages-এ চালু করার নিয়ম

1. GitHub-এ নতুন একটা repository বানাও (যেমন `orthi-birthday`)।
2. এই ফোল্ডারের সব ফাইল সেখানে আপলোড করো।
3. Repository-র **Settings → Pages** এ যাও।
4. **Branch** হিসেবে `main` আর ফোল্ডার `/ (root)` বেছে **Save** চাপো।
5. কয়েক মিনিট পর লিংক পেয়ে যাবে: `https://তোমার-ইউজারনেম.github.io/orthi-birthday/`

সব ফাইলের পথ relative, তাই subdirectory-তেও ঠিকঠাক চলবে। কোনো গান নেই, কোনো সার্ভারও লাগে না।
